# Changelog

## 0.1.0 — 2026-09-08

- Publicación como release normal tras la confirmación del usuario: descargada de GitHub y funcional en varios aspectos comprobados.
- Instalador `.drfx` y macro `.setting` idénticos byte a byte a v0.1.0-beta.1; no se modifica el título.
- Enlaces de descarga y documentación actualizados. La beta anterior se conserva.
- Sigue pendiente documentar una comprobación exhaustiva de controles, exportación y otras plataformas.

## 0.1.0-beta.1 — 2026-09-08

Primera publicación para probar la descarga de GitHub y la instalación en DaVinci Resolve.

- Texto editable con desplazamiento en perspectiva y desvanecimiento hacia el horizonte.
- Estrellas procedurales con cantidad, brillo, tamaño y semilla ajustables.
- Fondo con color y opacidad editables; posibilidad de usar una pista inferior.
- Instalador `.drfx` original y alternativa `.setting`, sin modificaciones respecto a la beta local.
- Documentación en español e inglés, instrucciones de prueba, sumas SHA-256 y validación automática.
- Vistas orientativas claramente identificadas como simulaciones externas.

Pendiente: instalación y render dentro de Resolve; reconocimiento de controles y rendimiento.
