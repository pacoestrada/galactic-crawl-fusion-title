# Galactic Crawl v0.2.0

Nueva presentación de Paco Estrada para el título Fusion con texto en perspectiva y estrellas editables de DaVinci Resolve 21.

El texto genérico de aventura espacial se sustituye por una presentación breve de Paco: comunicación y producción sonora, divulgación tecnológica, GNU/Linux, software libre, IA aplicada y automatización. El cierre invita a empresas y personas con una idea o una necesidad concreta a ponerse en contacto.

El grafo, los 23 componentes publicados, las expresiones y los valores de animación son los mismos de v0.1.0. El `.drfx` se ha reconstruido porque el texto forma parte del título; v0.1.0 se conserva sin cambios.

## Instalar

1. En **Assets**, descarga **Galactic-Crawl.drfx**.
2. Abre un proyecto en DaVinci Resolve y arrastra el archivo a la página **Fusion**.
3. Confirma la instalación y busca **Galactic Crawl** en la biblioteca de títulos.

Si ya tienes instalada una versión anterior, instala v0.2.0 para recibir el nuevo texto de ejemplo. Para una primera prueba, usa un clip de 60–90 segundos a 1920 × 1080.

También se incluyen el `.setting` alternativo, una guía rápida y sumas SHA-256.

## Validación

Sintaxis Lua, estructura, referencias, integridad ZIP, coincidencia de las dos copias del `.setting` y sumas SHA-256 verificadas. La vista previa también se ha actualizado, pero sigue siendo una simulación orientativa y no un render de Fusion. El paquete reconstruido queda pendiente de una prueba manual completa en Resolve.
