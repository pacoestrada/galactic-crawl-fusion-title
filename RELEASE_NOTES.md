# Galactic Crawl v0.1.0

Primera release normal del título Fusion con texto en perspectiva y estrellas editables para DaVinci Resolve 21.

El usuario ha confirmado que la descarga de GitHub funciona y que el título es funcional en varios aspectos comprobados. **El instalador `.drfx` conserva exactamente los mismos bytes de la beta probada; no se ha modificado el título.** La versión anterior v0.1.0-beta.1 se conserva.

## Instalar

1. En **Assets**, descarga **Galactic-Crawl.drfx**.
2. Abre un proyecto en DaVinci Resolve y arrastra el archivo a la página **Fusion**.
3. Confirma la instalación y busca **Galactic Crawl** en la biblioteca de títulos.

Si ya tienes instalada la beta, no necesitas reinstalar: el título es idéntico. Para una prueba nueva, usa un clip de 60–90 segundos a 1920 × 1080.

También se incluyen el `.setting` alternativo, una guía rápida y sumas SHA-256.

## Validación

Sintaxis, estructura, integridad del paquete y descarga verificadas. Funcionamiento de varios aspectos confirmado por el usuario. Queda pendiente documentar una revisión exhaustiva de controles, exportación, rendimiento y otras plataformas. Las vistas del repositorio siguen siendo simulaciones orientativas, no renders de Fusion.
